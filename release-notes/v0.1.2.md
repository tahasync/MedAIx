## Features
- Connect report upload, OCR, plain-language explanation, patient profile, risk trends, and wellness in one signed-in flow.
- Add account-scoped wellness logging with condition-aware goals and offline-safe syncing.
- Show lab-value trends with threshold and alert details based on saved report results.

## Fixes
- Make upload retries safe to repeat so a network retry does not create a duplicate report.
- Keep a successfully scanned report when its explanation fails, and allow the explanation to be retried without uploading again.
- Refresh trend context and wellness goals after profile edits; clear related server and local health data when the user deletes it.

## Bug fixes
- Correct report, trend, and wellness cache/API synchronization across retries, profile changes, and health-data deletion.
- Preserve report history and explain the available recovery action when only part of an upload succeeds.
