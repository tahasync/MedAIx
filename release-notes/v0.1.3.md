## Features
- Support CBC reports whose columns are printed as test, reference range, unit, then result.

## Fixes
- Read CBC values from the final result column instead of mistaking reference-range bounds for patient results.
- Keep the printed reference interval attached to its row for status and trend comparisons.
- Omit a range-first row when OCR did not capture a separate result, rather than showing a reference bound as a result.

## Bug fixes
- Fix incorrect Hemoglobin, WBC, RBC, HCT, MCV, MCH, MCHC, platelet, and differential-count values on the supplied report layout.
- Remove common OCR arrow artifacts appended to `g/dL` and `/uL` units.
