# MedAIx 0.1.5

- Refresh the Flutter app's navigation, report history, trends, upload flow, onboarding, and settings.
- Improve loading, empty, error, and recovery states across the app.
- Add reduced-motion support and setting-aware haptic feedback for key actions.
- Use the report's original date in trend history when it is available.
- Keep the component gallery debug-only and improve handling of internal OCR errors.
- Expand Flutter and API regression coverage and document the design and engineering conventions.

MedAIx explanations are generated by fixed rules and are not a diagnosis. Always check results against the original report and discuss concerns with a qualified clinician.
