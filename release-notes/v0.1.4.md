# MedAIx 0.1.4

- Report history now explains whether values were checked, need attention, or are still waiting to be explained.
- Re-adding the same report opens the saved copy instead of creating another entry.
- Report titles and dates are read more carefully, including dates printed with a named month.
- The app uses clearer light and dark colours, including easier-to-see switches and more readable report cards.
- Trend details and help text are clearer about how automated explanations are made.
- Health information saved on the device is excluded from Android backups.

MedAIx explanations are generated by fixed rules and are not a diagnosis. Always check results against the original report and discuss concerns with a qualified clinician.
